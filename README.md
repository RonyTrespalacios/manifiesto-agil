# Manifiesto Ágil - Los 12 Principios

Una página web interactiva que presenta los 12 principios del Manifiesto Ágil de manera visual y atractiva.

## 🌐 Demo

**[Ver página en vivo](https://ronytrespalacios.github.io/manifiesto-agil/)**

## ✨ Características

- **Modo oscuro** con diseño moderno
- **Tarjetas interactivas** con efectos hover
- **Modales informativos** con ejemplos de dificultades e importancia
- **Diseño responsive** optimizado para móviles y escritorio
- **Footer sticky** con enlaces a GitHub

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla

## 📱 Responsive

- **Escritorio**: Layout de 2 columnas (1,7; 2,8; etc.)
- **Móvil**: Lista lineal secuencial (1, 2, 3, 4...)

## 🎯 Uso

Simplemente abre `index.html` en tu navegador o visita la página desplegada.
